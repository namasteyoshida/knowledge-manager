## 1. 記事CRUD

| No | 機能 | 前提条件 | 手順 | 期待結果 | 備考 |
|---|---|---|---|---|---|
| 1-1 | 記事作成(自由入力) | ログイン不要 | `/pages/new`を開き、タイトル・著者・本文を入力し保存 | 記事詳細ページに遷移し、内容が正しく表示される | |
| 1-2 | 記事作成:必須項目未入力 | 同上 | タイトルまたは本文または著者を空のまま保存を試みる | 保存ボタンが非活性で送信できない | |
| 1-3 | 記事作成:タイトル重複 | 既存記事と同名のタイトルで作成 | 同名タイトルで保存 | **現状:重複したままエラーなく保存される**(unique制約なし) | 本来は重複エラーを出すべき |
| 1-4 | 記事編集 | 既存記事が1件以上ある | 詳細→編集→本文変更→保存 | 詳細ページに戻り、改訂履歴が1件増える | |
| 1-5 | 記事編集:書き込み中断時の整合性 | (実機での再現は困難) | Revision作成後にPage更新が失敗するケースを想定 | transactionで囲み中で失敗したらロールバック |  |
| 1-6 | 記事削除 | 既存記事が1件以上ある | 詳細→削除→確認ダイアログでOK | 一覧から消え、URL直打ちで404になる | |
| 1-7 | 記事削除:存在しないID | 既に削除済み、または不正なpageIdを指定 | 削除処理を実行 | 本番環境でもエラーメッセージが正式に表示される |  |
| 1-8 | 記事一覧表示 | 記事が1件以上ある | `/pages`を開く | タイトル・著者・更新日が正しく表示される | |
| 1-9 | 記事一覧:大量データ時の表示 | 記事が11件以上ある(要テストデータ投入) | `/pages`を開く | **現状:ページネーションがなく、全件が1画面に表示される** | 無限スクロール化でも対応可能 |

## 2. Markdown編集機能

| 2-2 | ツールバー:太字 | 本文の一部を選択した状態 | 「B」ボタンを押す | 選択範囲が`**`で囲まれる | |
| 2-3 | ツールバー:箇条書き | 記事作成/編集画面 | 「•」ボタンを押す | カーソル位置(行頭)に`- `が挿入される | |
| 2-4 | ツールバー:リンク | 本文の一部を選択した状態 | 「🔗」ボタンを押す | 選択範囲が`[ ]`で囲まれ、直後に`(url)`が追加される | |
| 2-5 | リアルタイムプレビュー | 本文に何か入力する | 入力後、少し待つ | 3秒程度後にプレビューへHTMLとして反映される | |
| 2-6 | テンプレート入力モード切り替え | `/pages/new`を開く | 「テンプレート入力」ボタンを押す | 5セクション(結論/背景・課題/原因・ポイント/対応方法・手順/注意点・まとめ)の入力欄が表示される | |

| 2-8 | テンプレート:各セクションのツールバー独立性 | テンプレート入力モード | あるセクションでツールバー操作する | 他のセクションの内容に影響しない | |
| 2-9 | テンプレート保存 | 5セクション全て入力済み | 「記事として保存」を押す | `## 1. 結論`等の見出し付きMarkdownとして記事が作成される | |
| 2-10 | サニタイズ | 記事作成/編集画面　| <script>が埋め込まれた記事を保存し、記事詳細を開く | <script>が発動せず文字としても表示されない | |

## 3. 検索

| No | 機能 | 前提条件 | 手順 | 期待結果 | 備考 |
|---|---|---|---|---|---|
| 3-1 | タイトルでの検索 | 記事が存在する | 一覧の検索ボックスにタイトルの一部を入力し検索 | 該当記事がヒットする | |
| 3-2 | 本文(最新)でのキーワード検索 | 記事が存在する | 最新本文に含まれる語で検索 | 該当記事がヒットする | |
| 3-3 | 過去の改訂にのみ存在する語での検索 | ある記事を編集し、旧本文にのみ含まれていた語がある | その語で検索する | ヒットしない | 現状全ての記事の最新版を取得しJSで絞り込む設計のため記事数が増えるごとにパフォーマンス低下する |
| 3-4 | 存在しないキーワードでの検索 | - | 該当記事がない語で検索 | 「該当する記事が見つかりませんでした」と表示される | |
| 3-5 | 削除済み記事の除外 | 削除済み記事がある | その記事のタイトル・本文で検索 | 検索結果に表示されない | |
| 3-6 | 検索結果のページネーション | 検索結果が11件以上になるキーワードがある | 検索を実行する | **現状:ページネーションがなく、全件が1画面に表示される** |  |
| 3-7 | 呼称の正確性 | ドキュメント確認 | 要件定義書・README上の機能名を確認 | **現状:「全文検索」と表記されているが、実装は単純な部分一致検索であり、形態素解析・ランキング等は行っていない** | 呼称の訂正が必要 |
